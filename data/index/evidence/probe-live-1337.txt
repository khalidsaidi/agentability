Rule for "unreadable" — a domain counts as judged if ANY of these yields content, in order:
  1. GET https://<domain>/ with "AgentabilityBot/2.0 (+https://agentability.org/methodology)"  -> >= 50 prose words
  2. the same GET with a browser UA                               -> >= 50 prose words
  3. the same GET against www.<domain> with a browser UA          -> >= 50 prose words
  4. robots.txt + sitemap.xml, HTTP 200 only                      -> > 20 tokens
A prose word excludes any token containing braces, semicolons, equals, quotes or slashes, so bundled
JavaScript does not count as a readable page. A non-200 at step 4 is an error page, not evidence.
